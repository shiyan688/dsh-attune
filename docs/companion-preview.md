# 0.2.0 默契小屋预览版

## 体验

打开 DSH，点角落里的大肥鱼女仆。她会在等待时轻轻摆动，出题时歪头想一想，确认偏好后开心跃起。角色可以收起、换到另一侧；设置保存在当前终端。关闭动画或启用系统“减少动态效果”会停用这些动画。

「做个小测试」了解日常协作偏好；「教我怎么问」了解插件的提问语气、称呼和邀请方式。每道题由 DSH 配置的模型生成。答案先出现在确认卡片中，可修改再记住，也可直接放弃。「默契小本本」可以纠正与删除；删除时可一起忘记来源答案。语气偏好不会进入普通 DSH 对话的系统提示。

桌宠使用 DSH 的 `shell.overlay` 公共插槽，仅在 DSH 窗口内呈现。移动 Web 使用全屏小屋与紧凑角色区。DSH Go 原生入口使用其公开 JSON 面板组件；该入口当前显示角色状态文案、按钮与卡片，动画女仆用于 Web 渲染入口。DSHA、Whaleness 的实际表现取决于是否加载宿主 Web 插件。原生端也可使用 `/attune tone`、`/attune test` 及确认、纠正、删除命令。

- 37 项自动测试通过，包含旧档案兼容、普通与语气偏好分离、待确认不生效、确认后使用、纠正后替换、删除后遗忘、DSH Go 取消恢复及 HTTP/命令入口。
- Edge 桌面与 390/320 像素窄屏验证：打开桌宠、生成题目、选择、确认、语气生成、纠正、删除及遗忘、桌宠换边、隐藏恢复、关闭动画、刷新保留设置。窄屏无横向溢出。使用独立示例生成器验收 UI，实际插件不包含示例题库。
- `dsh-attune-0.2.0.tgz` 已通过隔离 DSH Web profile 安装与配置加载，认证后的 `/api/attune/state` 和 `/tests` 返回 200；非法主题被拒绝，无模型凭据时生成失败明确可见。
